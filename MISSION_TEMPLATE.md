# PREY Mission Template

Use this compact template for every new mission. Replace bracketed text; do not turn unknowns into claims.

## Mission [number] — [name]

**Objective:** [One bounded outcome this mission must produce.]

**Known evidence:**

- [VERIFIED FACT / OBSERVATION with source or repository path]

**Unknowns:**

- [The exact uncertainty this mission may resolve]

**Allowed actions:**

- [Specific research, documentation, exposure, delivery, or implementation actions]

**Forbidden actions:**

- [Explicit scope, safety, build, outreach, experiment-isolation, spending, and agent boundaries]

**Budget:** [Research hours/sources/candidates; build/demo time; cash; exposure window; check cadence. Default to the V2 limits unless stricter.]

**Distribution gate:** [Named approximately US$0 surface, target-user presence, current rule/access evidence, permitted format, and opt-in response path—or UNKNOWN.]

**Success condition:** [Observable fact that completes the mission; distinguish learning from revenue.]

**Kill/stop condition:** [Predetermined evidence, deadline, budget limit, safety issue, or execution boundary that stops work.]

**Required evidence persistence:** [Files/ledgers to update; timestamps; source links; labels; screenshots or artifacts if appropriate; privacy exclusions.]

## Final factual report

- **MISSION:** [COMPLETE / PARTIAL / BLOCKED]
- **OBJECTIVE RESULT:** [exact]
- **NEW VERIFIED FACTS:** [exact or none]
- **MARKET SIGNAL:** [noise / interest / buying intent / transaction counts]
- **CUSTOMERS / PAID RUNS / REVENUE:** [verified values]
- **CASH SPENT:** [verified value]
- **DECISION:** [BUILD / ITERATE / RETEST / RESERVE / KILL / INCONCLUSIVE / not applicable]
- **EXPERIMENTS CHANGED:** [IDs and exact changes, or none]
- **ARTIFACTS:** [paths]
- **SCOREBOARD CHANGES:** [exact, or none]
- **NEXT CHECKPOINT:** [date/event and required action]
- **BLOCKER:** [none or exact execution block]

Do not report research, a prepared kit, engagement, an execution block, or repository activity as market validation, a customer, a paid run, revenue, software, or an autonomous agent.
